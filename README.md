# Felsare3 Website

الموقع التعريفي الرسمي المبدئي لمشروع **فالسريع**.

## المرحلة الحالية
- موقع تعريفي Responsive
- الصفحة الرئيسية
- عن فالسريع
- الخدمات
- الانضمام (Coming Soon)
- التواصل والدعم
- دعم أكثر من رقم هاتف وواتساب

## تعديل بيانات التواصل
حاليًا بيانات التواصل موجودة في:

`src/main.tsx`

داخل:

```ts
const CONTACTS: ContactItem[] = [
  { label: "الدعم والطلبات", value: "010...", type: "phone" },
  { label: "واتساب فالسريع", value: "2010...", type: "whatsapp" }
];
```

- `phone`: يفتح تطبيق الاتصال.
- `whatsapp`: يفتح محادثة واتساب مباشرة.
- يمكن إضافة أي عدد من الأرقام.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

## مبدأ المشروع
الموقع الحالي بسيط ومقصود به إطلاق الهوية والخدمة أولًا. لا يوجد Backend أو نظام طلبات أو Admin Panel في هذه المرحلة. يمكن تطوير هذه المكونات لاحقًا حسب احتياجات التشغيل الفعلية.
